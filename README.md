# Ginnungagap Rift — Theme for Obsidian (v2.0)

> *Die gähnende Leere zwischen Niflheims Eis und Muspelheims Glut.*  
> *The primordial chasm between Niflheim's ice and Muspelheim's fire.*

**Ginnungagap Rift** is a major v2.0 evolution of the Ginnungagap theme. Designed for cosmic horror, Nordic sci-fi, worldbuilding, and TTRPG campaigns (such as LANCER and Norse mythos), it transforms Obsidian into an active cosmological anomaly: the note itself is the Rift — an abyssal cosmic chasm where glacial frost from the north collides with the smoldering embers of the south.

![Ginnungagap Rift Showcase](assets/screenshot.png)

---

## 🌌 Dual Polarity Experience

* **Dark Mode — "Ginnungagap":** Pitch-black void backdrop surrounded by deep-space starfields. Top headers and frost elements inherit glacial ice hues (`#9cc4d8`, `#cfe0ea`), while footer regions and selections burn with Muspelheim embers (`#e14132`, `#ff733d`).
* **Light Mode — "Niflheim":** Frostbitten bone-white manuscript parchment with icy glacial borders, contrasting deep charcoal text, and stark blood-red accents.

## ⚙️ Style Settings Integration

Customizable in real-time via the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) community plugin under **Settings → Style Settings → Ginnungagap Rift**:

| Option | Description & Choices |
| :--- | :--- |
| **Pol / Polarity** | • **Ginnungagap (Balanced):** Embers inside, glacial ice outside.<br/>• **Muspelheim:** Everything shifts to glowing fire and ember.<br/>• **Niflheim:** Pure glacial ice and frost throughout. |
| **Book Headings** | Switch heading typography between chiseled `Cinzel` small-caps and literary `Crimson Pro`. |
| **Starfield** | Toggle the subtle deep-space celestial star particles in the workspace frame. |
| **Explorer Runes** | Toggle Elder Futhark rune prefixes (`ᚠ`, `ᚢ`, `ᚦ`, `ᚬ`, `ᚱ`, `ᚴ`) on folders and files. |
| **Ymir Chromatic Glitch** | Toggle the fire/ice chromatic aberration glitch effect on paracausal `[!ymir]` callouts. |

## 📥 Installation

### Manual Installation
1. Download `theme.css` and `manifest.json` from the [repository](https://github.com/ShakToth/Ginnungagap-Obsidian-Theme).
2. Inside your Obsidian vault, navigate to `.obsidian/themes/`.
3. Create a folder named `Ginnungagap Rift` and copy both files into it.
4. Open **Settings → Appearance → Themes** and select **Ginnungagap Rift**.
